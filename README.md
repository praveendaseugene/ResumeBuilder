# OpenSource Resume Builder

A free, open-source, professional resume builder with live preview, AI-powered CV import, and multiple export formats. Build stunning resumes instantly with no sign-up required.

**Try it now:** [https://praveendaseugene.github.io/ResumeBuilder/](https://praveendaseugene.github.io/ResumeBuilder/)

No installation needed - just open and start building your resume!

## ✨ Features

- **📝 Live Preview** - See changes in real-time as you edit your resume
- **🎨 Multiple Templates** - Modern, Minimal, Creative, Classic, and Executive styles
- **🎯 AI-Powered CV Import** - Upload PDF/DOCX/TXT and let AI parse your data
- **📱 Responsive Design** - Works perfectly on all devices
- **🔄 Undo/Redo** - Full undo/redo support (Ctrl+Z/Ctrl+Y)
- **🎨 Theme Customization** - Choose from 36 accent colors
- **✏️ Rich Text Editor** - Format text within text areas
- **📸 Photo Support** - Upload and crop profile photos
- **📄 Multi-Page Export** - PDF, PNG, JPEG, and TXT formats
- **🌙 Dark Mode** - Toggle between light and dark themes
- **💾 Auto-Save** - Data persists in browser localStorage
- **📋 Custom Sections** - Add any custom section (Publications, Awards, etc.)
